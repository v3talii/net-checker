# net-checker

A lightweight Bash CLI utility for network availability checking, ping response time measurement, and log archiving.

##  About the Project
This project was built as part of my learning journey in Linux administration and Bash scripting (TU Dublin studies). 
I used AI as an assistant to learn new commands, understand script logic, structure the code properly, and speed up development.

## Usage

1. Make the script executable:
   chmod +x netcheck.sh
